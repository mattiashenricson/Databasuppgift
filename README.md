# Databasuppgift
Projektuppgift - utveckling av databasapplikation

## Projekt

- **`vaderonskningar/`** – Väderönskan 🌤️: en webbplats där kunder kan önska
  väder för en specifik dag. 10 kr per önskan eller 50 kr/månad för fritt antal
  önskningar. Se [vaderonskningar/README.md](vaderonskningar/README.md).
- `app.js` – tidigare gruppuppgift (parkeringshusets bokningssystem).
